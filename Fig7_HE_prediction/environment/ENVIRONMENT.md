# Analysis environment

- Python 3.10
- Install: `python -m pip install -r environment/requirements.txt`
- Arial must be installed to reproduce the manuscript figure typography.
- Prov-GigaPath embeddings, patient manifests, outcomes, regional targets and image assets are external inputs and are not included.

The scripts start from frozen 1,536-dimensional Prov-GigaPath tile embeddings; raw-slide preprocessing and feature extraction are outside this package.
